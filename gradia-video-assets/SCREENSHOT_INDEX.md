## Important evidence boundaries

- Gemini had no configured server key. Fresh generation did not succeed. Samples in screenshots 18, 21–25, 27 and 47 are preloaded demo content.

- Screenshot 26 shows the dashboard fallback to a saved missed topic after demo plan blocks were marked complete. There is no dedicated weak-topic report page.
- Screenshot 31 is actual five-minute break completion, not a 25-minute study completion.
- Original browser profiles and academic data were never used or reset. All actions happened in newly created nonpersistent browser contexts.
